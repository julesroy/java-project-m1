# Java Project M1

Mon projet repose sur les éléments suivants :
- JAVA 25
- Maven
- JUnit (pour les tests unitaires)
- Jackson Tools (pour la lecture des fichiers JSON)
- [f1db](https://github.com/f1db/f1db) (base de données gratuite et open source)

NB : certains fichiers sont plus courts dans mon projets que dans le repo f1db car je les ai raccourci pour ne traiter que la saison 2026.
